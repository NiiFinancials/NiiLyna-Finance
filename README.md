# NiiFinancials Free

A free, offline-capable personal finance and life organizer for Ghana.

## Publish with GitHub Pages
1. Create a **public** GitHub repository named `niifinancials`.
2. Upload the files from this folder to the **root** of the repository (not a nested folder). Keep `index.html` at the root.
3. In repository Settings > Pages, select Deploy from a branch, `main`, `/(root)` and Save.
4. Open `https://YOUR-USERNAME.github.io/niifinancials/` after publishing.

## Privacy and limitations
This version stores personal entries in the browser's localStorage, not a cloud account. Records do not sync between devices. Export a backup regularly and do not use shared devices for private financial records. This prototype is not a bank, payment service or financial adviser. GitHub Pages hosts the public app code, not your local transaction entries.
